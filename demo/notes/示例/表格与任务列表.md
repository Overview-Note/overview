### 内容较宽的表格

| 字段 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `id` | string | — | ULID，全局唯一 |
| `title` | string | 文件名 | 展示标题 |
| `tags` | string[] | `[]` | 用于过滤与搜索 |
| `public` | bool | `false` | 是否出现在只读文档站 |
