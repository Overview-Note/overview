# 代码块示例

带语言标注的围栏代码块会触发对应的语法高亮。

## Go

```go
package main

import "fmt"

func main() {
    for i := 1; i <= 3; i++ {
        fmt.Printf("tick %d\n", i)
    }
}
```

## Bash

```bash
set -euo pipefail
make build
OVERVIEW_DATA_DIR=./demo ./bin/overview serve --addr :5230
```

## TypeScript

```typescript
interface Note {
  id: string;
  title: string;
}

export async function search(q: string): Promise<Note[]> {
  const res = await fetch(`/api/v1/search?q=${encodeURIComponent(q)}`);
  if (!res.ok) throw new Error(`search failed: ${res.status}`);
  return res.json();
}
```

## Python

```python
from dataclasses import dataclass


@dataclass
class Note:
    id: str
    title: str


def titles(notes: list[Note]) -> list[str]:
    return [n.title for n in notes]
```
