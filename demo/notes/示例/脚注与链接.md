# 脚注与链接

## 脚注

GFM 脚注[^1]会随 Markdown 一起保存，编辑器里以节点形式保留[^portable]，
导出为 HTML 时自动编号。

你可以写多个脚注[^3]，引用顺序不影响最终编号[^2]。

[^1]: 脚注定义可以出现在文末任意位置。
[^2]: 编号按引用出现的先后顺序生成。
[^3]: 定义与引用一一对应。
[^portable]: 脚注保持纯文本可移植性，不依赖任何外部服务。

## Wiki 双链

内部链接用 `[[目标]]`，可选别名 `[[目标|显示文字]]`：

- [[功能总览|返回总览]]
- [[代码块示例]]
- [[表格与任务列表]]

目标按「完整路径 → 路径 + .md → 标题 → 文件名 → id」的顺序解析。
