# 部署

## 单二进制

```bash
make build
OVERVIEW_DATA_DIR=/var/lib/overview ./bin/overview
```

## Docker

```bash
docker compose up -d
```

默认监听 `:5230`，数据卷挂载到 `./data`。

## 关键环境变量

| 变量 | 默认 | 说明 |
| --- | --- | --- |
| `OVERVIEW_ADDR` | `:5230` | 监听地址 |
| `OVERVIEW_DATA_DIR` | `./data` | 数据根目录 |
| `OVERVIEW_AUTH` | `multi` | `multi` 或 `none` |
| `OVERVIEW_RENDER` | 空 | 设为 `true` 变为公开只读文档站 |
