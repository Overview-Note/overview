# 搜索与双链

## 全文搜索

顶栏搜索（`Ctrl / Cmd + K`）基于 SQLite FTS5。中文使用 **unigram + bigram** 分词，
因此「并发模型」「发模」这类中缀都能命中；英文按词加前缀匹配。

试试搜索这些词：

- `搜索`
- `Markdown`
- `演示`

## 双链

用 `[[目标]]` 建立关联。目标解析顺序为：完整路径 → 路径 + `.md` → 标题 →
文件名 → id。例如 [[功能演示]] 与 [[编辑器]]。

右侧「链接」面板会显示**反向链接**（谁引用了我）与**外部链接**；
未创建的链接可一键创建。
