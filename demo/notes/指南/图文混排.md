# 图文混排

## 插入图片

附件以 vault 相对路径存放，例如 `assets/preview.png`。编辑器会把它解析为
`/assets/preview.png` 提供服务；导出静态站时 `overview build` 会自动递归拷贝
`assets/` 目录（若附件存于 S3，则改以公开前缀直接引用，不拷贝本地文件）。

![Overview 界面预览](assets/preview.png)

*图 1：Overview 的编辑界面。*

## 图文并排

Markdown 本身不支持左右并排，通常用表格或 HTML 实现：

| 图示 | 说明 |
| :---: | --- |
| ![预览](assets/preview.png) | 左列放图，右列用文字补充说明 |

> 若 `demo/assets/` 下暂时没有图片，上面的 `<img>` 会显示为占位符；
> 把任意图片放到 `demo/assets/` 并保持文件名一致即可。

## 图片说明

图片的 `alt` 文本会作为可访问名称，请写有意义的描述，而不是 `图片1`。
