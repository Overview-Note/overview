# 编辑器指南

## 斜杠命令

在空行输入 `/` 即可唤出命令菜单：标题、列表、待办、引用、代码块、表格、公式、图表等。

## 快捷键

| 操作 | 快捷键 |
| --- | --- |
| 全局搜索 | `Ctrl / Cmd + K` |
| 加粗 | `Ctrl / Cmd + B` |
| 斜体 | `Ctrl / Cmd + I` |
| 行内代码 | `Ctrl / Cmd + E` |

## 图片

支持粘贴、拖拽与文件选择上传；可在设置中开启上传前自动压缩（WebP/JPEG）。

## 可见性

右上角可在「私有 / 公开」之间切换。公开的笔记可通过 `/public/<路径>` 匿名只读访问。
